# A balanced blind structure

Use fifteen-minute levels for a lively family game or twenty-minute levels when you want more room to play.

| Level | Small blind | Big blind |
|---:|---:|---:|
| 1 | 25 | 50 |
| 2 | 50 | 100 |
| 3 | 75 | 150 |
| Break | — | — |
| 4 | 100 | 200 |
| 5 | 150 | 300 |
| 6 | 200 | 400 |
| 7 | 300 | 600 |
| 8 | 400 | 800 |
| 9 | 500 | 1,000 |
