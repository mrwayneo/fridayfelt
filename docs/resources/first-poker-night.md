# Your first family poker night

A relaxed plan that keeps the lesson short and makes the game feel special.
{: .ff-page-intro }

| Time | Plan |
|:--|:--|
| 6:30 pm | Dinner and set up |
| 6:50 pm | Ten-minute poker lesson |
| 7:00 pm | Cards in the air |
| After Level 3 | Five-minute break |
| After the game | Hand of the night |

## Starting stack

| Chip | Quantity | Value |
|---:|---:|---:|
