# Friday Night Poker Tour

Twelve events. One season champion. Plenty of stories in between.
{: .ff-page-intro }

## Season format

| Detail | Format |
|:--|:--|
| Events | 12 regular poker nights |
| Players | 3–9 per event |
| Scoring | 3 points enter the pool per player |
| Starting stack | 2,100 |
| Blind levels | 15 minutes |
| Season prize | Bracelet and perpetual trophy |

## What makes it a tour

The leaderboard gives every event context, but the rituals make the season memorable: the previous winner brings the champion’s card protector, the defending champion opens the game, and the season winner earns a permanent place on the trophy.

{: .champion }
The card protector passes to each event winner. The season bracelet belongs to its winner forever.
