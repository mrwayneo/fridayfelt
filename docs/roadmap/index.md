# Friday Felt roadmap

Start with useful resources. Learn from real poker nights. Build only what home leagues genuinely need.
{: .ff-page-intro }

- **Now:** Guides, lessons, structures and downloadable resources
- **Next:** Better printable tournament packs and leaderboard templates
- **Later:** Optional league management, player profiles and statistics
