## The Friday Felt formula

1. Keep the first lesson to ten minutes.
2. Give every player the same starting stack.
3. Use fifteen-minute blind levels.
4. Award three points per player by finishing position.
5. Celebrate the winner—and the best decision of the night.

{: .lesson }
Teach only one idea before each game. A small success players can recognise at the table builds confidence faster than a long strategy lecture.
