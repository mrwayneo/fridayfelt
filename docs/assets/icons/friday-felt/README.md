# Friday Felt icon set

Custom outline icons for navigation and action cards.

- Grid: 64 × 64
- Stroke: 3
- Caps and joins: round
- Colour: `currentColor`
- Fill: none
- Recommended sizes: 20–24px in navigation; 32–40px on action cards

## Icons

`spade`, `house`, `diamond`, `club`, `heart`, `graduation-cap`, `crown`,
`trophy`, `two-cards`, `calendar-day`, `open-book`, `download`, `settings`,
`star`, and `results`.

Use CSS to set colour:

```css
.ff-icon {
  width: 22px;
  height: 22px;
  color: #b98bff;
}
```
