# Hall of Champions

Tournament results fade. Traditions—and the stories attached to them—last.
{: .ff-page-intro }

## Three symbols of achievement

| Recognition | Tradition |
|:--|:--|
| Previous event winner | Champion’s card protector |
| Season champion | Engraved bracelet |
| Family legacy | Perpetual trophy |

{: .champion }
The previous winner brings the card protector to the next event and uses it until a new champion earns it.

## Season champions

The first name will be engraved after Event 12.
